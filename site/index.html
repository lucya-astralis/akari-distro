Akari OS · Paketquelle

Die Pakete von Akari OS für Debian 13 (trixie): ein Desktop im Browser für jeden Rechner.

Einbinden

sudo curl -fsSLo /usr/share/keyrings/akari-archive-keyring.gpg @URL@/akari-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/akari.sources @URL@/akari.sources
sudo apt update
sudo apt install akari-desktop akari-base

Danach zeigt die Konsole die Adresse, unter der Akari OS im Browser läuft.

Kanäle

  • stable: die veröffentlichten Versionen
  • testing: der aktuelle Stand, jede Nacht neu gebaut

Schlüssel

Signiert mit @FPR@ (akari-archive-keyring.asc). Das Paket akari-archive-keyring hält ihn danach aktuell.
